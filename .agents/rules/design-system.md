# PromptKeeper 2.0 — Design System Rules

1. **Aesthetic Direction**: Premium, restrained developer SaaS workspace. Deep charcoal backgrounds, refined dark & light themes, restrained amber/orange accent (`#f0a532` / `#f97316`).
2. **Clutter Elimination**: Avoid loud neobrutalist borders, excessive gradients, heavy glassmorphism, and visual noise. Favor crisp typography, subtle borders (`rgba(255,255,255,0.08)` / `rgba(0,0,0,0.08)`), and structured geometry.
3. **Consistency**: Use shared design tokens for spacing, typography, radius, elevations, and states.
4. **Responsive Shell**: Provide an adaptive application shell (collapsible sidebar, global top bar, command palette, unified cards, and detail inspector) that scales gracefully from mobile viewports to ultra-wide displays.
5. **Keyboard & Accessibility**: Support full keyboard navigation (⌘K/Ctrl+K search, ⌘N/Ctrl+N create, Escape dismiss), high-contrast readability, and accessible ARIA attributes.
